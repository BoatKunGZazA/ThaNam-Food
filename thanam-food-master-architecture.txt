==================================================
2. CORE ARCHITECTURE
==================================================

เลือก:
MODULAR MONOLITH + API

ไม่เริ่มด้วย Microservices

ภาพรวม:

Internet
 ├── Customer Web
 └── Back Office + POS
          ↓
        Nginx
          ↓
      NestJS API
          ↓
   Business Core Modules
          ↓
 PostgreSQL / Redis / Storage
          ↓
        Worker
          ↓
 Printer / Notification / File Jobs / Reports

หลัก:
1. PostgreSQL = Source of Truth
2. Backend = Business Authority
3. Frontend ห้ามเข้าฐานข้อมูลโดยตรง
4. Business Rule อยู่ Backend
5. Online/POS/Table ใช้ Core เดียวกัน
6. Order Engine เป็นศูนย์กลาง
7. Printer ไม่ใช่ผู้ควบคุม Order
8. Realtime เป็นเพียง Transport
9. External Provider ต้องเปลี่ยนได้
10. Settings ที่ร้านต้องเปลี่ยนเองห้าม Hardcode
11. Critical Action ต้อง Audit
12. รองรับหลายสาขาใน Architecture ตั้งแต่ต้น
13. Responsive เป็น Core Requirement
14. Build Once → Deploy Anywhere
